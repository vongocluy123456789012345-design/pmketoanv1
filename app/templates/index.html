Mỗi tháng tải xong, trong thư mục tháng có

  • TongHop_YYYY-MM.xlsx – danh sách hóa đơn, link mở XML/PDF, trang "Can chu y" (HĐ thay thế, điều chỉnh, bị hủy, thiếu XML/PDF)
  • XuatPMKT_YYYY-MM.xlsx – chi tiết từng dòng hàng (sheet Mua vào / Bán ra) để nhập phần mềm kế toán
  • Thư mục từng loại: BangKe_*.xlsx, XML\, PDF\ (bản gốc; bản in từ cổng có đuôi _hddt.pdf)

Đọc hóa đơn hàng loạt (PDF / XML / ZIP / ảnh scan)

Kéo thả nhiều file hóa đơn (hoặc file .zip chứa nhiều hóa đơn). Phần mềm đọc ký hiệu, số, ngày, MST, tên, tiền hàng, thuế, tổng thanh toán, mã CQT, mã tra cứu; rồi so với dữ liệu đã tải từ cổng thuế (khớp / lệch tiền / không có trên cổng / đã bị hủy). Bản scan / ảnh chụp (PDF ảnh, JPG, PNG) được đọc bằng OCR – cột "Nguồn" ghi OCR, nên kiểm tra lại các dòng báo thiếu.

Đối chiếu sao kê ngân hàng ↔ hóa đơn

Kéo thả file sao kê (Excel, CSV, PDF, hoặc bản scan / ảnh chụp – Vietcombank, Techcombank, MB, ACB, VietinBank, BIDV, Agribank, VPBank…). Bản scan đọc bằng OCR theo từng dòng; chiều tiền vào/ra xác định theo biến động số dư. Phần mềm tự nhận cột, rồi ghép từng giao dịch với hóa đơn đã tải trong khoảng ngày sao kê theo số tiền, số hóa đơn / MST / tên đối tác trong nội dung. Kết quả: giao dịch đã khớp, hóa đơn chưa thấy thanh toán, giao dịch chưa có hóa đơn (tô vàng khoản chi từ 20 triệu).

Đối chiếu tờ khai thuế GTGT 01/GTGT với hóa đơn

Chọn file tờ khai (XML nộp qua eTax hoặc Excel xuất từ HTKK). Phần mềm tự nhận kỳ (tháng/quý), cộng hóa đơn đã tải theo từng chỉ tiêu và báo Khớp / LỆCH. Cần tải trọn các tháng của kỳ đó trước.

Tự động tải hóa đơn hằng tháng

Đến ngày/giờ đã đặt, phần mềm tự tải hóa đơn của THÁNG TRƯỚC. Phần mềm phải đang mở. Muốn tự mở cùng Windows: đặt shortcut của run.bat vào thư mục Startup (Win+R → shell:startup).

* cần bạn nhập captcha khi tới lịch (có tiếng báo). Chưa đăng nhập cổng thì phần mềm mở Chrome, báo Windows và thử lại mỗi 15 phút.

Nhập hóa đơn từ file tải trên cổng thuế (miễn phí)

Đăng nhập hoadondientu.gdt.gov.vn trên Chrome/Edge → Tra cứu → Tra cứu hóa đơn → chọn khoảng ngày → Xuất Excel (danh sách) và/hoặc tải XML từng hóa đơn (file .zip). Kéo thả tất cả file .xml / .zip / .xlsx / .xls vào đây. Có XML thì phần mềm mới lấy được PDF gốc.

Tự động nhập file vừa tải về

Bật lên rồi cứ tải XML/Excel trên cổng thuế như bình thường – phần mềm tự phát hiện file mới trong thư mục, tự nhận file thuộc MST khách hàng nào, tự nhập và lấy PDF. File có sẵn từ trước khi bật sẽ không bị nhập.

Đang tắt

Kho hóa đơn trên Supabase (phần cũ của phần mềm): xem danh sách đã đồng bộ, lấy lại / upload PDF. Đăng nhập cổng trực tiếp bằng API có thể bị cổng chặn – nên dùng mục Tải hóa đơn.

1. Đăng nhập cổng hoadondientu.gdt.gov.vn
